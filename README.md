# Selective Solutions

Landing page for Selective Solutions LLC, an IT support company in Conyers, GA.
Selective Solutions provides managed IT, cybersecurity, backup and recovery,
3CX telephone systems and Microsoft 365 email for Georgia businesses, with
on-site service around Conyers and Covington and remote support everywhere else.

## What's here

```
index.html          The site. Generated by build.ps1. Open it or serve it.
site.webmanifest    Web app manifest (icons, theme colour).
assets/             Logo, favicons, SS monogram, hero poster and the hero background videos.
src/                Sources the site is built from. Edit these, not index.html.
wordpress-theme/    The same site as an installable WordPress theme (PHP).
docs/WIREFRAME.md   The conversion wireframe the layout was planned from.
build.ps1           Rebuilds index.html and regenerates the theme.
.nojekyll           Tells GitHub Pages to serve assets/ verbatim.
```

## View it locally

Open `index.html` in a browser. For the fonts and video to load reliably, serve
it over HTTP rather than the `file://` protocol:

```bash
# Python 3
python -m http.server 8000
# then visit http://localhost:8000
```

## Host it on GitHub Pages

1. Push this folder to a GitHub repository (see below).
2. In the repo, go to **Settings > Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, pick
   the `main` branch and the `/ (root)` folder, and save.
4. The site goes live at `https://<your-username>.github.io/<repo-name>/` within
   a minute or two.

The folder is already a git repository with its work committed on `main`, so
you only need to add the remote and push:

```bash
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```

`index.html` is at the repo root and every path in it is relative, so Pages
serves it as the home page with no extra configuration, including from a
`/<repo-name>/` sub-path.

## Editing the site

`index.html` is generated with all CSS and JS inlined, so do not edit it by hand.
Edit the sources instead:

```
src/_head.html      <head> contents: title, meta, favicons, fonts, structured data
src/_body.html      Page markup and all visible copy
src/css/theme.css   All styles (colour tokens at the top, sampled from the logo)
src/js/main.js      All interaction (tabs, diagram, calculator, security check, forms)
```

Then rebuild:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

That regenerates `index.html`, and also rewrites `wordpress-theme/style.css`,
`wordpress-theme/front-page.php` and `wordpress-theme/assets/js/main.js` from the
same sources and mirrors `assets/` into the theme, so both deliverables stay in
step. `functions.php` and `index.php` are edited in place.

## The WordPress theme

`wordpress-theme/` is a self-contained theme (`style.css`, `front-page.php`,
`functions.php`, `index.php`, `screenshot.png`, `assets/`). GitHub Pages ignores
it because Pages does not run PHP. To use it, copy the folder into a WordPress
install under `wp-content/themes/`, activate it, then set a static front page
under **Settings > Reading**.

In WordPress the "Request a meeting" form and the "Call me back" form post to
`admin-post.php` and email the lead with `wp_mail`. The destination address
defaults to info@selectivesolutions.com and can be changed under
**Settings > General > Selective Solutions lead email**. Make sure the host can
send mail (an SMTP plugin is the usual fix if it can't).

## Notes

- The static site has no server, so on GitHub Pages both forms open the
  visitor's email app with the request filled in, addressed to
  info@selectivesolutions.com. The WordPress theme sends them for real.
- The hero background video is a 1080p, 4.2 MB re-encode of the 19 MB 4K
  original (`assets/video/selective-hero.mp4`), with a 960px, 1.3 MB version
  for phones (`selective-hero-mobile.mp4`). Both are well within GitHub's limits.
- Nothing outside the hero uses footage from the video. Section visuals are
  inline SVG in the logo colours.
- Fonts (Archivo, Public Sans, IBM Plex Mono) load from Google Fonts, so the
  live site needs an internet connection for the intended typography.
- The supplied logo has a black tagline that disappears on the dark header.
  `assets/images/selective-logo-light.png` is a generated variant with only the
  tagline lightened. The original is kept in `selective-logo.png`. The supplied
  logo is 250 x 97 px; a larger file would look sharper on high-DPI screens.
- Favicons (`favicon.ico`, 16/32 px, Apple touch icon, 192/512 px) and the SS
  monogram in the hero diagram were generated from the supplied
  Selective Solutions Favicon.png.
- Motion respects `prefers-reduced-motion`: the custom cursor, magnetic buttons,
  hero video, word reveal, counters, marquee, diagram cycling and scroll reveals
  are off or static, and numbers show their final values.

## Before launch

Every unverified detail is marked `[CONFIRM: ...]` in the page text and shows
on the page as a dashed yellow tag. Search `src/_body.html` for `CONFIRM`,
replace each with the real answer (or delete the sentence), then run
`build.ps1`:

1. About timeline: 1995 first services or clients; anything else from 1999;
   the year phone systems were added; the year managed IT with monitoring started.
2. Comparison table: break-fix rate or billing method; whether the 1-hour
   guarantee covers managed clients only; whether backups and security training
   are in the monthly plan; the four break-fix cells.
3. Onboarding steps: time from first call to monitoring; meeting format and
   length; what the review covers and whether it's charged; setup time; review
   meetings or reports.
4. Service area: the 7 county names (the map uses Rockdale, Newton, Walton,
   Jasper, Morgan, DeKalb and Henry from the current website), in the section
   text and the FAQ.
5. FAQ: what the managed IT monthly price is based on.
6. Field notes: a one-line summary of "Setting up staff to work safely from home".

Also worth confirming: the spellings "SteelShield" and "Atul Vohra" (the current
website shows "StealShield" and "Atul Votra"), business hours, social profiles,
and permission to list the partner and platform names.
